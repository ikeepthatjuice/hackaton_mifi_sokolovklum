# Обезличенные результаты

[results.csv](results.csv) — числовая сводка; [TEST_RESULTS.md](../../docs/TEST_RESULTS.md) объясняет источники и пробелы, [PROTOCOL.md](../../docs/PROTOCOL.md) — процедуру, [LIMITATIONS.md](../../docs/LIMITATIONS.md) — границы вывода. В этом каталоге нет аудио, эталонов, текстов диалога, экспортов реального кейса и raw-логов.

## Формат CSV

UTF-8, запятая, одна строка на измерение/ожидаемый сценарий. Пустая ячейка означает «не сообщено / неприменимо», **не ноль**. Поля со значениями и запятыми заключены в кавычки стандартным csv.writer.

- status: reported — сообщил тестировщик; failed_reported — сообщён неуспех; pending — ожидается повтор; not_run — этот вариант ещё не проверен. Ни один reported не означает личный прогон автора документов.
- evidence_source — ссылка на источник, evidence_ref — SHA снимка источника. source_commit/apk_sha256 — именно проверенный артефакт; оставлены пустыми, если их связь с прогоном неизвестна.
- elapsed_ms/copy_ms/audio_duration_ms — миллисекунды; rtf — elapsed_ms/audio_duration_ms только для завершённой обработки. duration_approx=true у округлённых 11 с.
- elapsed_min_ms/elapsed_max_ms и rtf_min/rtf_max — сообщённый диапазон стадии; не набор придуманных повторов.
- peak_pss_mb/peak_rss_mb — единицы как в исходном сообщении (МБ), не пересчитаны в байты; sampling-метод старых пиков неизвестен.
- llm_completed_utterances/llm_total_utterances — только реально сообщённые N/M; неизвестные счётчики не вычислять по тексту warning или числу слов. changed/guard смотреть в notes либо в новом подробном отчёте.
- export_validation: reported_pass только для заявленного чужого PASS; pending/not_run для ожидаемых проверок; пустое поле — экспорт здесь не тестировался.

Русский post-fix диалог — строка pending без вымышленных результатов; заменить/дополнить после отчёта Ярика, сохранив идентификатор и evidence. Для нового прогона использовать поля из PROTOCOL, отдельную строку на каждый cold/warm повтор. Если схема дополняется, синхронно обновить этот README.

Публичный jfk.wav остаётся в upstream whisper.cpp, не в git этого проекта. Даже при успешной проверке реального экспорта публиковать только агрегаты и verdict.
