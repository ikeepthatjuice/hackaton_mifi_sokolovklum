# Ограничения Release v1.0

Срез: commit `f571636846fe35231405a78ad3fb2463cff18c67`. Основание чисел — [итоговый отчёт Ярика](https://github.com/ikeepthatjuice/hackaton_mifi_sokolovklum/issues/47#issuecomment-6717862616); это результаты команды, не собственный прогон автора документа. Установка Release проверена отдельно от измерительных тестов; SHA APK последних в отчёте не приведён.

- **Только русский язык.** ASR — GigaAM-v3 RNN-T с пунктуацией. Английский в текущем релизе не поддерживается. Whisper не является ASR этого Release.
- **Скорость A51:** русский диалог 73,5 с — 160,9 с обработки, RTF 2,19. Диаризация / ASR / LLM: 80,7 / 43,1 / 22,2 с. Это медленнее реального времени; непрерывный часовой прогон и устойчивость к троттлингу не подтверждены.
- **LLM в бюджете обрабатывает часть реплик; в финальном отчёте — 0 из 9.** При пропуске/ошибке остаётся исходный текст ASR и warning о необработанных репликах. Пунктуацию уже даёт ASR. Это не подтверждение успешной LLM-коррекции всех реплик. Валидатор разрешает LLM менять лишь регистр и знаки; он не исправляет ошибки распознавания и не восстанавливает пропущенные ASR отрицания.
- **Говорящие:** Pyannote + CAM++ в отчёте выделили 2 говорящих для диалога с 3 голосами. DER не измерен. Перекрытия речи, короткие ответы и сходные голоса могут приводить к пропускам и ошибкам кластеризации. Порог из PR #50 и его результаты не относятся к Release v1.0.
- **WER 3,38% — небольшой FLEURS ru набор:** 15 клипов / 296 слов. Это не оценка всей русской речи. Сравнимый WER Whisper на том же наборе и финальный RTF FLEURS не сообщены; RTF 2,19 относится к диалогу.
- **Хранилище:** не менее 2 ГБ свободного места, включая APK, копию весов и временные файлы; PCM float32 mono 16 kHz — около 230,4 МБ/час. Потребление RAM и холодный/тёплый старт финального Release отдельно не измерены в опубликованном итоговом отчёте.
- **Источник Qwen GGUF:** сторонняя квантовка [prithivMLmods](https://huggingface.co/prithivMLmods/Qwen3-0.6B-GGUF/tree/3fa3255253c99e212675c0825241518cdba8e42c), Apache-2.0; исходная модель Qwen3-0.6B. Хеши, размеры и лицензии — в [manifest](../models/manifest.json) и [README](../README.md#источник-локальной-llm).
- **Новые UI-фичи:** переименование, ручная правка, склейка, история, копирование и проигрывание фрагментов требуют отдельного интеграционного QA соответствующих feature PR. Этот документ не заявляет их проверенными на Release. Экспорт содержит фиксированные поля `speaker_id/start_ms/end_ms/text`; произвольные имена говорящих не являются полями этой схемы. Поддержка и сохранение UI-имён в feature PR здесь не подтверждены.
- **Материалы сдачи:** ссылка на видео пока не предоставлена; ответ организаторов о размере APK и роли LLM не подтверждён. Не выдаём эти пункты за закрытые.

Методика — [PROTOCOL](PROTOCOL.md), финальные агрегаты — [TEST_RESULTS](TEST_RESULTS.md), подробные прежние LLM-эксперименты — [LLM_KV_PERFORMANCE](LLM_KV_PERFORMANCE.md). Промежуточные APK и их замеры не смешиваются с финальным CSV.
