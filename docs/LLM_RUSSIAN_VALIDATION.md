# Qwen3-0.6B Q4_K_M: русская синтетическая регрессия

7 ноября 2026. Результат для PR #13. Основной язык проекта — русский; английский поддерживается. Приоритет этого прогона — сохранность русских слов, имён, чисел, отрицаний и коротких ответов.

## Вывод

**Q4_K_M иногда портит русские слова. Валидатор и настоящий LocalTranscriptPostprocessor откатили все обнаруженные искажения к точному rawText.** Это не отчёт о безошибочности модели: в 4/16 русских ответов потребовался откат. Финальный displayText сохранил слова и metadata на 16/16 русских примерах.

| Проверка | Результат |
|---|---|
| Реальный Q4 inference на русском | 16/16 завершены, runtime errors 0 |
| Вывод модели принят без изменения слов | 12/16 |
| Искажение слов/имён, откат к rawText | 4/16 (25%) |
| Принятый вывод реально изменил регистр/оформление | 3/16 |
| Принятый вывод совпал с исходным | 9/16 |
| Финальный production guard: слова/числа/metadata сохранены | 16/16 RU, 2/2 EN |
| Короткие русские да / нет / да нет / нет не надо | 4/4 приняты, модель оставила их неизменными |
| Намеренно испорченные ответы, отдельные controls | 15/15 отвергнуты, точный rawText восстановлен |
| Допустимая пунктуация/регистр, отдельные controls | 6/6 приняты |

На принятых русских ответах модель исправила только регистр имён в трёх случаях; добавления знаков препинания не получено. Поэтому прохождение guard не является доказательством полезной пунктуации. Q4 остаётся резервным кандидатом с обязательным guard, а не гарантированно качественным форматировщиком.

Русские ошибки модели: «илья» → «Иля»; «не меняем» → «Нет менять»; добавление «Нет» перед фразой; изменение имени «сю́бик» → «субик». Во всех четырёх случаях production processor выдал исходную строку без изменений (строковое равенство), событие FORMAT_REJECTED зарегистрировано. Ни одно испорченное слово не попало в финальный displayText.

Английский sanity check: 1/2 ответов модели принят, 1/2 откатан. На `yes` модель выдала `Да Нет`; guard вернул `yes`. На длинной английской фразе сохранены слова, исправлен регистр и добавлена точка. Это ограниченная проверка двух примеров, не оценка качества английского ASR/LLM в целом.

## Проверка настоящего отката

В реальном прогоне использован **LocalTranscriptPostprocessor из #6**, а не вручную написанная имитация `if accepted`. TextGenerator оборачивает настоящий LlamaCppTextGenerator, захватывает исходный ответ Q4 и передаёт его обычному processor. Для каждой реплики проверены:

- INFERENCE_COMPLETED зарегистрирован ровно один раз;
- id, speakerId, startMs, endMs и rawText не изменились; порядок/количество/говорящие всего набора совпали;
- при отклонении ответа displayText точно равен rawText и есть FORMAT_REJECTED;
- финальный результат принят тем же TranscriptValidator.

Отдельные 15 намеренно испорченных controls передают фиксированный ответ через TextGenerator в тот же production processor. Они **не выдаются за ответы Qwen**. Проверены: да/нет, потеря отрицания, подмена имени, опечатка, е/ё, латиница внутри кириллицы, цифры → слова, потеря ведущего нуля, смена десятичного разделителя, потеря процента, перестановка слов, добавление слова, потеря минуса и замена числа. Все дали точный rawText. Шесть positive controls подтвердили, что допустимый регистр/знаки не откатываются.

Runtime failures и отмена не считаются успешным fallback: harness завершится ошибкой при runtime error или нарушении инварианта. Этот прогон завершился exit 0. Изменений production validator/processor не потребовалось; #6 этим коммитом не меняется.
