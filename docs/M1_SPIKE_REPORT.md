## 1. Цель и архитектурные результаты

Подтверждена автономная архитектура ASR и диаризации для Android APK без облачных сервисов:

1. **`WhisperAsrEngine` (`src/android/engine/asr/`):**
   - Интеграция с `whisper.cpp` (multilingual base, официальный тег `v1.7.1`, commit `ebca09a3d1033417b0c630bbbe607b0f185b1488`).
   - Статическая компиляция через CMake из сабмодуля `external/whisper.cpp` (`BUILD_SHARED_LIBS OFF`).
   - Язык по умолчанию: `language = "ru"`, поддержка переопределения (в тестах на английском `jfk.wav` передаётся `language = "en"`).
   - Потоковое блочное чтение PCM (буфер 64 КБ) для защиты от OOM на больших файлах.
   - **Гарантия строгой монотонности таймкодов (фикс M1):**
     - Отсечение служебных токенов в C++ JNI (`id >= whisper_token_eot(ctx)` и префиксы `[_` / `<|`) и в Kotlin.
     - Корректная склейка подслов: новое слово начинается с токена с пробелом (`" "`, `\u0120`, `\u2581`), `t0` берется от первого токена, `t1` — от последнего.
     - Нормализация по порядку: `start = max(start, prevEnd)`, `end = max(end, start + 1)`, `end = min(end, durationMs)`; отбрасывание слов за пределами `durationMs`.
     - Корректный масштаб времени: сотые доли секунды whisper переводятся в миллисекунды (`ms = t * 10`).
     - Флаги: `token_timestamps = true`, `split_on_word = true`.

2. **`SherpaOnnxDiarizationEngine` (`src/android/engine/diarization/`):**
   - Официальный Android prebuilt `sherpa-onnx v2.0.1` (`c-api.h`, `libsherpa-onnx-c-api.so`, `libonnxruntime.so`).
   - Модели диаризации: **Pyannote Segmentation 3.0** (`sherpa-onnx-pyannote-segmentation-3-0.onnx`) + **3D-Speaker ERes2Net base** (`3dspeaker_speech_eres2net_base_sv_zh-cn_3dspeaker_16k.onnx`).
   - Динамическое число говорящих без предварительной фиксации (`num_clusters = -1`, `clusteringThreshold = 0.6`).
   - Стабильное назначение `speaker_1`, `speaker_2` по первому появлению с сохранением ID при возвращении участника.
   - Потоковое блочное чтение PCM (64 КБ).

3. **`TranscriptAlignerImpl` (`src/android/engine/alignment/`):**
   - Точное сопоставление слов с интервалами реплик с учётом смены голоса внутри фраз и дедупликацией слов на стыках.

4. **Инструментальные тесты для CI-эмулятора и Unit-тесты:**
   - `WhisperAsrEngineTest.kt`: unit-тесты на синтетических токенах со всеми патологиями (перекрытия, $t_1 < t_0$, служебные токены, выход за пределы записи).
   - `WhisperOnDeviceTest.kt`: тестовый прогон на `jfk.wav`, строгая проверка монотонности, валидация слова "country", лог `ENGINE_TEST`.
   - `SherpaOnDeviceTest.kt`: валидация моделей сегментации и эмбеддингов, один спикер -> `speaker_1`, лог `ENGINE_TEST`.

## 3. Открытые вопросы и следующие шаги

1. **Сравнение Whisper Base vs Small (q5_1):**
   - После зелёного билда и мерджа PR #2 будет проведён сравнительный замер `base` vs `small-q5_1` (`ggml-small-q5_1.bin`, ~181 МБ) на разрешённом русском аудио. Если RTF на реальном телефоне будет $< 1.0$, в релиз пойдёт модель `small-q5_1` для максимального качества распознавания русской речи.
2. **Конфликт GGML (whisper.cpp vs llama.cpp):**
   - Обе библиотеки собираются статически со скрытой видимостью символов (`-fvisibility=hidden`), предотвращая коллизии в общем runtime.
3. **Доставка весов:**
   - Веса поставляются внутри assets APK (без сжатия `noCompress`) и распаковываются в `context.filesDir/models/`. В git веса не коммитятся.
