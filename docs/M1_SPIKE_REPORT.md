## 1. Цель и архитектурные результаты

Подтверждена автономная архитектура ASR и диаризации для Android APK без облачных сервисов:

1. **`WhisperAsrEngine` (`src/android/engine/asr/`):**
   - Интеграция с `whisper.cpp` (multilingual base, commit `18503b8`).
   - Прямая компиляция через CMake из сабмодуля `external/whisper.cpp`.
   - Потоковое блочное чтение PCM (буфер 64 КБ) для защиты от OOM на больших файлах.
   - Извлечение настоящих акустических word timestamps (`token_timestamps = true`, `whisper_full_get_token_data`). Без искусственного деления интервалов.
2. **`SherpaOnnxDiarizationEngine` (`src/android/engine/diarization/`):**
   - Стек `sherpa-onnx` (Silero VAD + Cam++ русский эмбеддинг + кластеризация).
   - Динамическое число говорящих (`num_clusters = -1`).
   - Стабильное назначение `speaker_1`, `speaker_2` по первому появлению с сохранением ID при возвращении участника.
3. **`TranscriptAlignerImpl` (`src/android/engine/alignment/`):**
   - Точное сопоставление слов с интервалами реплик с учётом смены голоса внутри фраз и дедупликацией на стыках.
4. **Инструментальные тесты для CI-эмулятора:**
   - `WhisperOnDeviceTest.kt` (тестовый прогон на `jfk.wav`, валидация слова "country", лог `ENGINE_TEST`).
   - `SherpaOnDeviceTest.kt` (валидация `speaker_1`, лог `ENGINE_TEST`).

## 3. Открытые вопросы и риски

1. **Конфликт GGML (whisper.cpp vs llama.cpp):**
   - Влияние на компоновку двух native-библиотек остаётся открытым вопросом. Тестируется совместно с Яриком и Сюбиком в общем приложении.
2. **Доставка весов:**
   - Веса поставляются внутри assets APK (без сжатия) и копируются в `context.filesDir/models/`. В git веса не коммитятся.
