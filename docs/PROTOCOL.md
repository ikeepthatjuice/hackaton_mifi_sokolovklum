## Повторение проверки

1. Собрать Release по [SETUP](SETUP.md) либо скачать APK из Release. Зафиксировать commit, вариант сборки, размер, `sha256sum <apk>`, модель устройства, Android, RAM и свободное место. Не подменять SHA тестовой сборки SHA пользовательского Release.
2. Для чистой установки удалить старую версию (удаляет её локальные данные), установить APK, дождаться копирования моделей. Включить авиарежим и отдельно выключить Wi-Fi. Проверить отсутствие INTERNET у установленного пакета. Сборка/скачивание весов требуют сети до офлайн-прогона.
3. Использовать синтетику или разрешённый публичный sample. Публичный FLEURS ru — для WER; содержательные материалы кейса не публиковать. В отчёт выносить только агрегаты и идентификатор разрешённого набора.
4. Cold — первый запуск обработки после перезапуска процесса; warm — повтор в том же процессе. Момент начала/конца таймера и включение копирования/загрузки моделей записывать отдельно. Здесь итоговый отчёт не разделяет cold/warm, поэтому опубликованные времена так не маркируются.
5. Измерять длительность исходного аудио и elapsed обработки; `RTF = elapsed_ms / audio_duration_ms`. Отдельно записывать стадии, N из M обработанных LLM реплик, предупреждения, крэши, пик PSS/RSS. Не сравнивать RTF разных наборов как одинаковый тест.
6. Сохранить экспорт и проверить `python3 quality/check_export.py <export.json>`. Проверка подтверждает структуру, порядок и интервалы; она не измеряет WER, корректность speaker identity или сохранение ручных правок. Сценарии редактирования — [Q1_TEST_PLAN](Q1_TEST_PLAN.md).

## Точность ASR

Использовать [quality/wer.py](../quality/wer.py): одинаковая нормализация эталона и гипотезы — Unicode NFC, нижний регистр, ё → е, все символы вне Unicode-категорий L/N/M заменяются пробелами, повторные пробелы схлопываются. Числа не переводятся в слова. WER = (S + D + I) / N.

```bash
python3 quality/wer.py <reference.txt> <hypothesis.json>
python3 quality/wer.py --no-digits <reference.txt> <hypothesis.json>
python3 quality/check_export.py <export.json>
python3 -m unittest discover -s quality/tests
bash scripts/check-forbidden.sh
```

`--no-digits` удаляет с обеих сторон токены, содержащие цифры; это отдельный вспомогательный показатель, не замена основного WER. Команда выводит только счётчики, не тексты. Для сравнения GigaAM/Whisper нужны один набор, одна нормализация и отдельные реальные прогоны; такого сравнения финальный отчёт не содержит.

## Публикация

[results.csv](../artifacts/test-results/results.csv) содержит только итоговые агрегаты финального commit и проверку установки Release. Пустое поле означает «не сообщено», не ноль. У каждого результата есть источник; отчёт команды не становится собственным измерением автора. Детальные схемы QA и прежние LLM-прогоны переиспользуются ссылками из [TEST_RESULTS](TEST_RESULTS.md).
